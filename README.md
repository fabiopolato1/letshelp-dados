# letshelp-dados

Causas da semana exibidas no site [letshelp.com.br](https://letshelp.com.br).

- `causes.json`: lista de vaquinhas ativas, com uma causa em destaque por categoria.
- Atualizado toda segunda-feira pela rotina semanal do Let's Help.
- O site lê este arquivo e, se o GitHub não responder, usa a cópia guardada na hospedagem.
